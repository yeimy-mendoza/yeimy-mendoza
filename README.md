## Hola, soy Yeimy

Soy **Ingeniera en Informática** con experiencia en desarrollo de aplicaciones web y sistemas institucionales. Me interesa crear soluciones útiles, mantenibles y centradas en las necesidades de las personas y las organizaciones.

Parte de mi experiencia profesional está en sistemas institucionales y repositorios privados, por lo que no todo ese trabajo se encuentra disponible públicamente en GitHub.

En este perfil compartiré proyectos, prácticas y aprendizajes relacionados con el desarrollo de software, bases de datos y análisis de información.

## En qué trabajo

- Desarrollo de aplicaciones web de extremo a extremo.
- Construcción de APIs y servicios con Python, Django y Django REST Framework.
- Interfaces web con React, Angular, JavaScript, HTML y CSS.
- Diseño, modelado y administración de bases de datos relacionales.
- Reportes y visualización de datos con Power BI.
- Modelado de procesos con BPMN.
